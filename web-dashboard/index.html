01 / Problem Statement

Why Frontier LLMs Drift in Localized Legal & Financial Ecosystems

While frontier Large Language Models excel at general English benchmarks (MMLU, GSM8K), they exhibit severe citation hallucination and numerical drift when deployed on contract-heavy Southeast Asian property law, multi-tier payment schedules, and floating-rate mortgage amortization.

FAILURE MODE 01

Phantom Statutory Citations

Models frequently attribute fabricated clauses or outdated thresholds to real statutory codes such as the Vietnam Land Law 2024, Housing Law 2023, and Real Estate Business Law 2023 (e.g., misstating deposit caps or foreign ownership quotas).

FAILURE MODE 02

Temporal Policy Conflation

In multi-document RAG pipelines spanning 2014–2026 developer sales policies (CSBH), models conflate historical phases or illegally combine mutually exclusive incentives—such as applying both a 0% interest subsidy and an upfront early-payment discount simultaneously.

FAILURE MODE 03

Amortization Arithmetic Drift

Free-form token generation fails to maintain exact precision across principal grace periods (ân hạn nợ gốc), daily early-payment cashflow discounts (ACT/365), deferred-construction split pricing (giãn xây), and statutory maintenance fees (KPBT).

Deterministic Programmatic Verification

Longitudinal Ground-Truth Corpus

Structured JSON schemas validated against data/schema.json covering multi-tier sales policies, statutory legal articles, deferred construction schedules, and multi-bank lending parameters.

  • Exact source context snippets & document provenance IDs
  • Mandatory verbatim/normalized citation spans (required_citations)
  • Adversarial trap definitions (forbidden_hallucinations)
src/cashflow_verifier.ts View source ↗

Deterministic Financial Verifier (CashflowVerifier)

Programmatic engine that computes exact mathematical ground truth for loan amortization, interest rate subsidies, and NPV cashflow discounts to grade LLM-generated financial tables.

  • Upfront discount cascade & ACT/365 early-payment interest math
  • Split land vs. construction VAT & post-discount KPBT (0.5% / 2.0%)
  • 24–36 month principal grace period & floating-rate schedules
src/evaluator.ts View source ↗

Strict Citation Attribution Scorer (CitationEval)

Evaluates whether model outputs strictly ground every numerical claim and legal condition in the provided context window without extrapolating unsupported terms.

  • Normalized Vietnamese diacritic-aware span verification
  • Zero-tolerance penalty for mutually exclusive policy blending
  • Supports Zero-Shot, Long-Context RAG, and Tool-Use (MCP) runs
03 / Evaluation Metrics & Reference Baselines

Quantitative Reliability Thresholds

Every evaluation run grades model responses across three orthogonal axes: citation grounding precision, hallucination containment, and exact financial arithmetic.

Metric Code Formal Definition Production Target
Strict Citation Precision SCP Percentage of required statutory/policy clauses accurately cited and grounded in exact source document spans > 98.5%
Zero-Hallucination Rate ZHR Percentage of evaluation items containing zero ungrounded claims or forbidden incentive combinations > 99.0%
Amortization Exact Match AEM Numerical accuracy within ±0.01% tolerance against CashflowVerifier ground truth across all cashflow lines 100.0%

05 / Quick Start & Reproducibility

Run the Evaluation Suite Locally

Clone the open-source repository from GitHub and run the deterministic verification suite against the ground-truth dataset.

1. Installation & CLI Execution 
git clone https://github.com/lequangtoanthang/vn-propfin-llm-benchmark.git
cd vn-propfin-llm-benchmark
npm install

# Run deterministic verifier & sample evaluation suite
export ANTHROPIC_API_KEY="your-api-key"
npm run eval:sample

# Run unit tests
npm test
